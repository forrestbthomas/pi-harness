# v0.3.0 Robustness & Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.3.0 — a robust, trustworthy daily-driver harness covering 8 prioritized gaps (session resume, eval timeouts/skip guard, build-time version, error-path polish, release automation, test coverage, contribution surface, subagent docs).

**Architecture:** All changes are in the Go CLI (`internal/cli/`) and the Python eval suite (`eval/`). Each gap is an independent, shippable task landing in priority order. Version is derived at build time via `-ldflags`; release uses a stdlib-only cross-compile script (no goreleaser).

**Tech Stack:** Go 1.21 (stdlib only), Python 3.11 + pytest + DeepEval, GitHub Actions, Bash.

## Global Constraints

- **Go 1.21, stdlib-only** — no external Go dependencies (no go.sum).
- **No hardcoded user paths in shipped code** — the existing portability scan (`internal/cli/paths_test.go`) enforces this. Split any literal like `/Users/forrestthomas` so it can't self-match.
- **Never log or echo API keys** — diagnostics report presence only.
- **Exit codes stay stable:** `0` ok · `1` generic · `2` usage · `3` missing key · `4` node/pi missing · `5` eval venv missing.
- **Python dependency ceiling:** `deepeval`, `pytest`, `python-dotenv`, `pypdf`, `pytest-timeout` only (eval venv).
- **Docs live in repo root / docs/;** no secrets in docs.
- **TDD:** write the failing test first, run it to confirm failure, implement, confirm pass, commit.
- **Frequent commits** — one per task (or per logical step).
- **`pi-run eval --quick` and `config-check` must pass with no API key** (CI runs them keyless).

```go
import (
	"fmt"

// supportedProviderKeyEnvs mirrors eval/conftest.py's SUPPORTED_PROVIDER_KEYS.
// Env-only (no Bitwarden) so the eval command never blocks on a vault.
var supportedProviderKeyEnvs = []string{
	"OPENROUTER_API_KEY",
	"OPENAI_API_KEY",
	"ANTHROPIC_API_KEY",
	"GEMINI_API_KEY",
	"GROQ_API_KEY",
	"DEEPSEEK_API_KEY",
}

// anyProviderKeyEnv reports whether any supported provider key is set in the
// environment (presence only; never the value).
func anyProviderKeyEnv() bool {
	for _, k := range supportedProviderKeyEnvs {
		if os.Getenv(k) != "" {
			return true
		}
	}
	return false
}

// runEval runs the DeepEval pytest suite. --quick runs the smoke subset.
func runEval(quick bool) int {
	root := repoRoot()
	evalDir := filepath.Join(root, "eval")
	venvPython := filepath.Join(evalDir, ".venv", "bin", "python")
	if _, err := os.Stat(venvPython); err != nil {
		fmt.Fprintln(os.Stderr, "pi-run: eval: eval/.venv missing — run `pi-run setup` first")
		return 5
	}
	args := []string{"-m", "pytest"}
	if quick {
		args = append(args, "tests/test_code_quality.py",
			"tests/test_agent_task_completion.py::test_dataset_expected_outputs_are_non_empty")
	} else if !anyProviderKeyEnv() {
		fmt.Println("No provider key found — run `pi-run doctor` to check keys. Skipping live tests.")
		args = append(args, "tests/test_harness_config.py", "tests/test_code_quality.py",
			"tests/test_agent_task_completion.py::test_dataset_expected_outputs_are_non_empty")
	}
	args = append(args, "-v")
	code, err := runCmd(venvPython, args, evalDir)
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		return 1
	}
	return code
}
```

- [ ] **Step 1: Write the release script**

Create `scripts/build-release.sh`:

```bash
#!/usr/bin/env bash
# build-release.sh <tag> — cross-compile pi-run for release.
#
# Produces bin/pi-run-<os>-<arch> for linux/darwin/windows × amd64/arm64,
# stamped with <tag> via -ldflags.
set -euo pipefail

if [ $# -ne 1 ]; then
  echo "usage: $0 <tag>" >&2
  exit 2
fi
TAG="$1"
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
LDFLAGS="-X github.com/forrestthomas1/pi-harness/internal/cli.Version=${TAG}"

cd "$ROOT"
mkdir -p bin

for GOOS in linux darwin windows; do
  for GOARCH in amd64 arm64; do
    EXT=""
    if [ "$GOOS" = "windows" ]; then EXT=".exe"; fi
    OUT="bin/pi-run-${GOOS}-${GOARCH}${EXT}"
    echo "building ${OUT} ..."
    GOOS="$GOOS" GOARCH="$GOARCH" CGO_ENABLED=0 go build -ldflags "$LDFLAGS" -o "$OUT" ./cmd/pi-run
  done
done

echo "done: $(ls bin/pi-run-* | tr '\n' ' ')"
```
