A mutable object can be changed in place after it is created (e.g., a list, dict, or set); an immutable object cannot be changed after creation (e.g., an int, str, tuple, or frozenset). Trying to modify an immutable object raises an error such as TypeError: 'tuple' object does not support item assignment for tuples; operations on immutable objects instead create and return a new object rather than changing the original. Because they cannot change, immutable objects are hashable (when their contents are also immutable), so they can be used as dict keys and set elements, while mutable objects cannot.
