# Simple Chatbot

This repository contains a simple chatbot application using Golang. It is designed for technical interview practice, specifically focusing on the setup and improvement phase as described in the interview guide.

## Getting Started

### Prerequisites

- Git
- Golang
- Node.js (for future integrations)
- Ensure that the required tools are installed with:

  ```bash
  git --version
  go version
  node --version
  ```

### Setup

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Change into the project directory:
   ```bash
   cd chatbot
   ```

3. Run the application:
   ```bash
   go run main.go
   ```

### Configuration

- Rename `.env.example` to `.env` and add your API keys.
- Ensure all configurations are set as needed for the application.

### Development

For development and improvements:
- Inspect the chatbot evaluation results.
- Make targeted improvements in `handlers`. Use tools like Codex for AI enhancements.
