A dict is implemented as a hash table: lookup computes a hash of the key and jumps straight to the bucket where the key would be stored, so an average lookup is O(1). A list stores values only by position, so finding a value requires a linear scan comparing each element until a match is found, which is O(n). Dict lookup requires the key to be hashable (which is why mutable objects like lists cannot be dict keys). The O(1) figure is the average case; the worst case is O(n) if many keys collide on the same hash bucket.
