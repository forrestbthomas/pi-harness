A list is an eager collection that stores all of its elements in memory at once; a generator is lazy and produces one value at a time (via yield) only as it is iterated. Generators use far less memory for large or infinite sequences, but they can be iterated over only once and do not support indexing, len(), or slicing. Use a generator when the sequence is huge, infinite, or you only need to iterate once (for example, reading a large file line by line); use a list when you need random access, repeated iteration, or the full collection.
