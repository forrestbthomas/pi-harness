When a Python file is run directly, Python sets its __name__ variable to the string "__main__"; when the file is imported as a module, __name__ is instead set to the module's name. The guard makes the code inside the block run only when the file is executed directly, not when it is imported. This is useful because it lets a single file serve both as a runnable script and as a reusable module: importing the module for its functions will not accidentally trigger the script's main logic or side effects.
